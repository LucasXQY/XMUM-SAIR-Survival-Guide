# EEE | 电子信息工程

资料按**课程**分目录：`EEE/<课程代码>_<课程名>/`，每门课一个文件夹，所有年份的试卷、大纲、作业都放在一起，文件名里的 `YYYYMM` 就是学期。想知道自己这一届哪一年上哪门课，看下面的「各届培养方案」。不同届课程代码可能变（例如 Engineering Graphics：2021 入学是大一的 COM204，2025 入学是大二的 EEE220），课程 README 里会互相注明。

Material is organised **per course**: `EEE/<CODE>_<Course_Name>/`, one folder per course, with papers, syllabi and assignments from every year together; the `YYYYMM` in each file name is the session. To see which course your cohort takes in which year, use the curriculum tables below. Course codes can change between cohorts (e.g. Engineering Graphics was COM204 in Year 1 for the 2021 intake and EEE220 in Year 2 for the 2025 intake); the course READMEs cross-reference each other.

「开课」一栏是「入学年 学年学期」，例如 `2021 Y1S3` 表示 2021 入学的同学在大一第三学期上这门课。本表由 `scripts/update_index.py` 自动生成，加完文件后运行一次即可。

"Taught" reads "intake year, year·semester": `2021 Y1S3` means the 2021 intake took it in Year 1 Semester 3. This table is generated by `scripts/update_index.py`; run it once after adding files.
