# EEE | 电子信息工程

资料按**课程**分目录：`EEE/<课程代码>_<课程名>/`，每门课一个文件夹，所有年份的试卷、大纲、作业都放在一起，文件名里的 `YYYYMM` 就是学期。想知道某门课大概什么时候修，看下面的「修课时间表」。不同届课程代码可能变（例如 Engineering Graphics：2021 入学是大一的 COM204，2025 入学是大二的 EEE220），课程 README 里会互相注明。

Material is organised **per course**: `EEE/<CODE>_<Course_Name>/`, one folder per course, with papers, syllabi and assignments from every year together; the `YYYYMM` in each file name is the session. To see roughly when a course is taken, use the course timeline below. Course codes can change between cohorts (e.g. Engineering Graphics was COM204 in Year 1 for the 2021 intake and EEE220 in Year 2 for the 2025 intake); the course READMEs cross-reference each other.

## 课程索引 | Course index

"Taken in" is the session (`YYYY-MM`) a contributor actually took the course, read from the timeline below; "Sessions covered" is every session that appears in file names, i.e. which sessions the repo has material for.
