# 教师名录 | Lecturers

这一页列出在各课程文件夹 README 学期表里出现过的老师，点进去看每位老师教过哪些课、哪个学期，以及通往课程页的链接。对课程和老师的打分只在课程页的「课程评价」里（匿名、1–5 分、按课程和老师列出、满 3 人显示平均分）。**本站不收关于老师的文字评价。** 老师本人如希望修改或移除关于自己的记录，发邮件到 `xieqiyi@ieee.org`。

This page lists every lecturer named in the session tables of the course READMEs; open one to see the courses and sessions they taught, with links to the course pages. Scores for a course and its lecturer live only in that course's review section (anonymous, 1–5, listed per course and lecturer, averages from 3 voters). **This site takes no written reviews of lecturers.** Lecturers who want their record changed or removed can email `xieqiyi@ieee.org`.

名单想多一位老师：上传那门课的资料时在表单里填上老师，或在课程 README 的学期表里补上。

To add a lecturer, name them in the upload form when you upload that course's material, or fill the lecturer cell in the course README's session table.
