# 教师档案 | Lecturer Profiles

这一页记录 SAIR 老师的授课风格、沟通方式和性格特点，帮助同学们选课、提问和找导师时心里有数。**只描述，不打分，不排名。** 写的时候想象老师本人会看到这一页。

This page describes SAIR lecturers' teaching style, way of communicating and personality, so students know what to expect when choosing courses, asking questions or looking for a supervisor. **Descriptions only: no scores, no rankings.** Write as if the lecturer will read it, because they might.

## 写作规则 | Ground rules

- 写具体、可观察的事实："板书多、PPT 少""课后邮件回得快""考试偏计算"，不写笼统的好坏评价。
- 不写人身攻击、外貌、私生活、健康、家庭、政治或宗教立场，不写任何私人联系方式。
- 性格描述用中性词（"严格""随和""话少""爱提问"），不用贬义词。
- 不同同学感受不同，欢迎补充不同角度，但不要删掉别人的描述。
- 老师本人如希望修改或移除关于自己的内容，发邮件到 `xieqiyi@ieee.org`，我们会立即处理。

- Be concrete and observable: "writes on the board more than slides", "replies to email quickly", "exams lean towards calculation"; avoid vague good/bad verdicts.
- No personal attacks, nothing about appearance, private life, health, family, politics or religion, and no private contact details.
- Describe personality in neutral words ("strict", "easy-going", "quiet", "asks a lot of questions"), never pejoratives.
- Experiences differ; add your own angle, but don't delete someone else's.
- Lecturers who want anything about them changed or removed can email `xieqiyi@ieee.org`; it will be handled at once.

## 档案 | Profiles

每位老师一个页面：教过的课、课程评分、同学描述。描述写在页面底部的评论区，登录 GitHub 即可，立刻可见，机器人按关键词事后折叠不合规的内容。名单来自各课程文件夹 README 的学期表，上传资料时填上老师，名单就会多出来。网页上在下面的框里输入老师名或课程代码，回车直达那位老师的评论区；在 GitHub 上看这个文件的话，请到 https://xmum-sair.github.io/lecturers/ 。

One page per lecturer: courses taught, course ratings, and what students say. Descriptions go in the comment thread at the bottom of the page (sign in with GitHub; visible at once; a bot folds disallowed content by keyword afterwards). Names come from the session tables in the course READMEs, so naming the lecturer when you upload material adds them here. On the website, type a name or course code in the box below and press Enter to land on that lecturer's comment area; if you are reading this file on GitHub, go to https://xmum-sair.github.io/lecturers/ .
