# GE | 公共课 (University-wide courses)

所有专业通用的课放在这里：`G` 开头的是全校选修课，`MPU` 开头的是马来西亚政府规定的必修通识课（马来语、马来西亚研究、社区服务等）。目录结构和 EEE 一样：`GE/<课程代码>_<课程名>/<YYYY-MM>/`。谁在哪个学期修了这些课，记在各自专业页的「修课时间表」里。用上传表单时，代码以 G 或 MPU 开头的课会自动放进这里，不管选的是哪个专业。

Courses shared by every programme live here: codes starting with `G` are university electives, codes starting with `MPU` are Malaysia's compulsory general subjects (Bahasa Melayu, Malaysian studies, community service and so on). Same layout as EEE: `GE/<CODE>_<Course_Name>/<YYYY-MM>/`. Who took them and when is recorded in each programme's "Course timeline". The upload form files any code starting with G or MPU here, whichever programme is chosen.
